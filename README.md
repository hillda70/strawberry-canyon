\# Strawberry Canyon



> “From a high place one can see all the roads below.”

>

> — inspired by Hiroshige



Strawberry Canyon is a lightweight market-state engine for discretionary macro and options trading.



It transforms structured market data into:



\- cross-asset state surfaces

\- volatility regime classification

\- directional force analysis

\- range utilization metrics

\- portfolio pressure diagnostics

\- actionable workflow outputs



The framework is designed for a:



```text

1 human + AI trading desk

```



\---



\# Core Philosophy



```text

Trade state, not price.

```



Strawberry Canyon focuses on:



\- directional force

\- force trajectory

\- volatility regime

\- movement exhaustion

\- cross-asset confirmation

\- structural location



The objective is not prediction.



The objective is recognizing:



\- transition

\- expansion

\- compression

\- instability

\- exhaustion

\- acceleration
