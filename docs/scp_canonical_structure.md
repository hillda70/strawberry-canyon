\# SCP Canonical Structure



\## Core Chart Structure



```text

Timeframe: 30-minute chart

Impulse: ROC13

Environment: ATRP14

Derived metric: Fragility Ratio

```



\---



\# Why ROC13 on 30m Matters



A regular NYSE session is:



```text

6.5 hours = 13 thirty-minute candles

```



Therefore:



```text

ROC13 on a 30-minute chart

```



is not just a generic momentum indicator.



It behaves like a rolling nowcast of full-session directional outcome.



It estimates how the current market is moving relative to one complete session-length memory window.



\---



\# Fragility Ratio



```text

Fragility Ratio = ROC13 / ATRP14

```



This measures:



```text

session impulse relative to environmental roughness

```



or:



```text

propagation efficiency relative to volatility cost

```



\---



\# Interpretation



| Fragility Ratio | Meaning |

|---|---|

| > 2.0 | Unstable propagation |

| 1.0 to 2.0 | Directional persistence |

| 0.0 to 1.0 | Weakening propagation |

| < 0.0 | Reversal / absorption |



\---



\# Conceptual Role



The SCP structure converts a 30-minute chart into a market-state estimator.



It is not asking:



```text

Is price going up or down?

```



It is asking:



```text

Is session impulse propagating efficiently relative to local roughness?

```
